# SocialPulse AI Dashboard
## Overview
SocialPulse AI is an interactive dashboard designed to provide insights into social media sentiment, trends, audience demographics, and network analysis. The dashboard features a modern dark theme and is fully responsive, ensuring a seamless experience across devices.

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd social-pulse-ai
   ```
3. Install dependencies:
   ```
   npm install
   ```
